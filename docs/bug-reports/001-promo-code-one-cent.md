# Customers charged one cent too much with a promo code

Reported by: support, 2026-09-21

A customer ordered one baguette tradition and one pain au chocolat with the code BIENVENUE10.
The receipt shows 2.30 €. The price list gives 2.55 € minus 10%, and the shop policy rounds
the discount to the nearest cent, so the customer expected 2.29 €. Several similar complaints
since the last release. Not every cart is affected.
